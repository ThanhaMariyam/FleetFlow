# FleetFlow - Fleet Management Portal

A modern, professional fleet management application designed for tracking vehicle conditions, active trips, driver schedules, and service requests.

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables in `.env.local`:
   ```bash
   VITE_TRANSLATION_API_KEY="your-translation-api-key"
   ```

3. Run the application locally:
   ```bash
   npm run dev
   ```
